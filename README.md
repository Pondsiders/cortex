# cortex

Alpha's memory.

Each memory is a unit in the Vault: `cortex/YYYY-MM-DD/<id>.md`, plus an optional
`<id>/` directory beside it holding attachments. The files are the truth. Everything
else — embeddings, full-text index, metadata — is a cache that can be deleted and rebuilt.

Project: **Cortex 2026.8 "Sprue."** Reasoning and decisions live in `CLAUDE.md`.
